# Network Inventory — Enterprise IT Support Lab

## 1. Project Information

* Project: Enterprise IT Support & Network Troubleshooting Lab
* Platform: Cisco Packet Tracer
* Purpose: Document network devices, IP addressing, VLAN assignments, and connectivity.

## 4. Network Configuration

* Switching: VLAN-based segmentation
* Trunking: IEEE 802.1Q
* Routing: Router-on-a-stick
* Connectivity testing: ping
* Windows diagnostics: ipconfig, nslookup, tracert

## 5. Notes

* PC0 belongs to the IT VLAN.
* PC1 belongs to the HR VLAN.
* PC2 belongs to the FINANCE VLAN.
* The router provides the default gateway for each VLAN.
* The switch-to-router connection carries traffic for the configured VLANs.
* The lab was tested for communication between departmental networks.
